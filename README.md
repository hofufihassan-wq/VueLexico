# سطر — منصة عربية لتعلّم البرمجة بالممارسة

منصة تعليمية تعمل بالكامل في المتصفح لتعلّم **HTML وCSS وJavaScript وVue 3** بالعربية: دروس متدرجة بتمارين تُصحَّح وظيفيًا، ومحرر بمعاينة معزولة، وشارح أكواد، ومختبرا CSS وJavaScript، ومحاكي تنفيذ مرئي، وقاموس، وتحديات ومشاريع، ومراجعة متباعدة، ولوحة تحكم — مع حفظ تلقائي ونسخ احتياطي.

> مشروع مستقل تمامًا: تصميم وبنية وتنفيذ أصلية، دون أي مستودع أو خدمة سابقة.

## التشغيل

المتطلبات: Node.js 20 أو أحدث.

```bash
npm install
npm run dev        # خادم التطوير على http://localhost:5173
npm run build      # نسخة إنتاج في dist/
npm run preview    # معاينة نسخة الإنتاج على http://localhost:4173
```

النسخة المبنية ملفات ثابتة (توجيه بالـ hash) يمكن رفعها على أي استضافة ثابتة. لا خادم، ولا قاعدة بيانات، ولا مفاتيح API.

> سكربتا `dev` و`build` ينسخان `vue.global.prod.js` إلى `public/vendor` تلقائيًا (تستخدمه معاينة Vue المعزولة). إن شغّلت `vite` مباشرة فشغّل `npm run vendor` أولًا.

## الاختبارات

```bash
npm test           # اختبارات الوحدة (Vitest): المحرك، المصحّحات، الشارحات، التخزين، سلامة المحتوى
npm run test:e2e   # اختبارات المتصفح (Playwright) على نسخة الإنتاج
```

اختبارات E2E تستخدم متصفح **Microsoft Edge** المثبّت (`channel: msedge`). لاستخدام Chrome: `PW_CHANNEL=chrome npm run test:e2e`، أو احذف `channel` من `playwright.config.js` بعد `npx playwright install chromium`.

داخل التطبيق توجد صفحة `#/selftest` تشغّل كل الحلول المرجعية عبر المصحّح الحقيقي.

## البنية

```
src/
  engine/        محرك التشغيل: تجهيز JS (acorn) وتتبّعه، بيئة التشغيل والمؤقتات الافتراضية،
                 Worker معزول، بناء المعاينة المعزولة (sandbox + CSP)، ترجمة Vue SFC، شرح الأخطاء،
                 وإعادة بناء الخط الزمني للمحاكي
  explain/       شارحات ثابتة: JavaScript وHTML (parse5) وCSS (css-tree) وVue (compiler-sfc)
  content/       الدروس (28) والقاموس (166 مصطلحًا) والتحديات والمشاريع
  store/         مخطط البيانات + التنقية + الحفظ التلقائي في localStorage + المراجعة المتباعدة
  components/    المحرر (CodeMirror 6) والمعاينة والطرفية ومساحة العمل والتمارين والاختبارات
  views/         الصفحات
tests/unit       اختبارات Vitest
tests/e2e        اختبارات Playwright
```
